# LuAshitacastProjects
LUA files for use with LuAshitacast, an Ashita v4 add-on for the 2002 MMORPG "Final Fantasy XI" (FFXI).

Universal LuAshitacast Profile

Runtime directory:
  Ashita\config\addons\LuAshitacast\\<CharacterName_CharID>\

Place Universal.lua and the 22 JOB.lua wrapper files in that directory.
The wrappers all load Universal.lua.
