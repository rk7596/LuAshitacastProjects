MOVEMENT-SPEED FIX (IMPORTANT)
-------------------------------
The original implementation did:
  gFunc.EquipSet(stateSet)
  then, while moving,
  gFunc.EquipSet(movementSet)

That caused visible equipment oscillation while moving because LuAshitacast repeatedly received competing Legs-slot requests at every poll. Standing still was stable because only the state set was sent.

The current working file fixes this by MERGING movement Legs into the current Idle/Resting/Engaged state and making ONE EquipSet() call per poll.

Established movement rule:
* At level 73+ for RDM, PLD, DRK, RNG, DRG, BLU, COR, RUN: Blood Cuisses.
* Everyone else: Track Pants +1.
* Track Pants +1 movement overlay intentionally contains no Feet entry.
* Mounted status ID 252 suppresses movement gear so mounted idle gear remains intact, notably BLU Magus Shalwar +1's augment.

Do not reintroduce a second movement EquipSet call.
